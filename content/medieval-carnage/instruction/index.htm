Instruction

Medieval Carnage is a two-player strategy game in which each player controls a castle.
The aim is to destroy the opponent's castle while protecting your own.
The first player to do so wins the game.

Players can only take the actions represented by the shown buttons.
Once a unit has been purchased, it moves and acts automatically.

Controls

On the start screen, there is a blue and a red button for selecting the respective player controls.

The following options can be selected by clicking on these buttons.

Click the action buttons with the left mouse button to apply them.
Use the Arrow keys to select the desired action button.
Press Enter to apply the selected action.
Use the WASD keys to select the desired action button.
Press Space to apply the selected action.
Let a computer bot control the player's actions.

This bot is advanced, but still rather beatable.

All of these options can be selected independently for both players.
This means that both local multiplayer and matches between bots are possible.

Coins

Players must earn coins in order to perform actions.
The number of coins required for each action is displayed on the corresponding button.
Both players' coin count automatically increases over time.

Lumberjack

Lumberjacks can collect trees that grow randomly on the battlefield to earn coins more quickly.

Small Tree
Medium Tree
Large Tree

Larger trees earn you more coins when collected and returned to the castle.

Melee Units

There are three types of melee units.

Pikeman
Swordsman
Knight

When two melee units clash on the battlefield, one of them is killed by the other, or they both kill each other.
Which unit is killed is determined by rolling a die, with the chances depending on the unit types.
It's basically a case of rock-paper-scissors.

  • Pikemen are strong against Knights
  • Knights are strong against Swordsmen
  • Swordsmen are strong against Pikemen

The stronger unit is more likely to kill the weaker unit than vice versa.
However, it is still possible for the weaker unit to kill the stronger one.

Any other type of unit (Lumberjack, Archer, Catapult) that clashes with a melee unit will always lose.

Ranged Units

There are three types of ranged units.

Archer
Catapult
Cannon

While Archers are strong against other units,
Catapults and Cannons can inflict significant damage to the opponent's castle.

Cannons are stationary units placed on the castle tower that shoot at the opponent's castle.

Each ranged unit has a limited number of shots and is removed after the last shot if not killed before.

Restore Castle

Repairs some of the castle's damage.

Upgrades

There are six types of upgrades.

Increases the rate at which the number of coins increase,
as well as earnings for each collected tree.
Increases the movement speed of all mobile units.
It increases the chances of all melee units killing opponent units.
It also reduces the likelihood of a unit being killed by ranged units.
Increases the shooting range, rate of fire, accuracy and number of shots of all ranged units.
Increases the damage that each unit, both melee and ranged, inflicts on the opponent's castle.
Reduces the time until an action can be performed again.

Each of these upgrades can be applied at most three times for maximum improvement.
The upgrade buttons show 0 to 3 lines as an indication of how many times the upgrade has already been applied.
Applying upgrades only affects units purchased afterwards and not those already on the battlefield.
